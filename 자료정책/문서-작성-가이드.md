# 문서 작성 가이드 — 핵심 이해 중심 시장 메모

이 저장소의 분석 문서는 **많이 알려주는 것보다 핵심을 빠르게 이해시키는 것**을 우선합니다.

기본 원칙은 `짧게 쓰되, 판단에 필요한 사실·원인·시장 의미·다음 확인사항은 남긴다`입니다.

## 1. 기본 구조

모든 분석 문서는 원칙적으로 아래 4개 구역만 사용합니다.

```text
1분 핵심
→ 왜 중요한가
→ 핵심 근거
→ 앞으로 볼 것
→ 출처
```

`깊게 보기`, 긴 역사, 반복 배경설명, 과도한 사건 타임라인은 기본적으로 만들지 않습니다.

## 2. 길이 기준

- 기존 장문 문서의 **절반 이하 분량**을 기본 목표로 합니다.
- 일반 분석 문서: 가능하면 **약 800~1,800자** 안에서 끝냅니다.
- 복잡한 정책·산업 문서도 특별한 이유가 없으면 **2,500자를 넘기지 않습니다.**
- 한 문단은 2~4문장 정도로 유지합니다.
- 같은 의미를 다른 표현으로 반복하지 않습니다.

길이를 맞추기 위해 중요한 사실을 빼면 안 됩니다. 대신 중요도가 낮은 배경·과거 사례·주변 정보부터 삭제합니다.

## 3. 무엇을 반드시 남길까

아래 내용만 우선 남깁니다.

1. **무슨 일이 벌어졌는가**
2. **왜 중요한가**
3. **확정된 것과 아직 기대인 것**
4. **주가·시장과 연결되는 핵심 근거**
5. **다음에 무엇을 확인해야 하는가**
6. **판단을 뒤집을 수 있는 핵심 리스크**

이 여섯 가지에 직접 도움이 되지 않는 정보는 과감히 생략합니다.

## 4. 1분 핵심

문서 맨 위에 3~5개 bullet 또는 작은 표 하나로 끝냅니다.

- 지금 무슨 일인가
- 가장 중요한 숫자 또는 사실
- 시장에서 왜 중요한가
- 현재 단계
- 다음 확인 이벤트

처음 읽는 사람이 이 부분만 읽어도 전체 논리를 이해할 수 있어야 합니다.

## 5. 왜 중요한가

배경을 길게 설명하지 말고 `원인 → 시장 영향`만 연결합니다.

예:

```text
AI 투자 확대
→ 첨단 패키징 수요 증가
→ 관련 장비 발주 증가 가능성
```

배경설명은 보통 2~4문장으로 충분합니다.

## 6. 핵심 근거

핵심 근거는 **최대 3~5개**만 남깁니다.

- 공시·정부·거래소·기업 발표
- 실적·매출·수주·투자금액
- 실제 사업 연결 관계
- 당일 수급·거래대금처럼 결론에 직접 필요한 시장 데이터

표를 쓰더라도 **2개 이하**, 한 표는 가능하면 **5행 이하**로 압축합니다.

## 7. 사실과 해석 구분

중요 내용은 필요한 경우 아래 라벨을 사용합니다.

- **[확정]** 공식 자료로 확인
- **[당사자 주장]** 기업·정부·관계자의 주장
- **[가능성 높음]** 복수 근거가 있으나 최종 확정 전
- **[시장 기대]** 시장에서 기대하지만 공식 확정 전
- **[추정]** 공개된 사실을 바탕으로 한 분석
- **[확인되지 않음]** 검증되지 않은 내용

라벨 자체를 많이 붙이는 것이 목적이 아닙니다. **중요한 불확실성에서만 사용합니다.**

## 8. 숫자는 핵심 숫자만

숫자는 결론을 이해하는 데 필요한 것만 남깁니다.

좋은 예:
- 매출 YoY +53%
- 계약금액 3,000억원
- 외국인 순매도 5,000억원

생략할 것:
- 결론에 영향을 주지 않는 세부 재무항목
- 비슷한 숫자의 반복
- 비교 의미가 없는 수치 나열

## 9. 종목 문서

종목 분석은 아래만 기본으로 봅니다.

```text
무슨 회사인가
→ 지금 왜 움직이는가
→ 실제 실적·수주·사업 연결 근거
→ 가장 큰 리스크
→ 다음 촉매
```

회사 연혁, 대표 약력, 전체 제품 목록, 고객사·경쟁사 전체 목록은 현재 판단에 필요할 때만 적습니다.

## 10. 산업·테마 문서

산업·테마는 아래 흐름만 유지합니다.

```text
테마가 생긴 이유
→ 지금 실제로 확정된 변화
→ 어떤 기업이 직접 연결되는가
→ 다음 촉매 / 소멸 조건
```

관련 종목은 많이 넣지 말고 **실제 연결이 강한 핵심 종목 위주**로 정리합니다.

## 11. 시황 문서

시황은 숫자 나열보다 **오늘 시장을 지배한 2~3개 변수**를 먼저 설명합니다.

가능하면 아래만 남깁니다.

- 지수와 장중 방향
- 외국인·기관·개인 핵심 수급
- 선물·프로그램·환율 중 방향 판단에 중요한 것
- 강한 업종·테마 2~4개
- 거래대금 상위 핵심 종목
- 급등락의 확인된 원인 / 가능성 높은 해석
- 오후장 또는 다음 거래일 변수

확보하지 못한 실시간 숫자는 억지로 채우지 않습니다.

## 12. 삭제 우선순위

문서가 길어지면 아래 순서로 줄입니다.

1. 같은 내용 반복
2. 오래된 배경설명
3. 결론과 무관한 세부 숫자
4. 주변 기업·관련 종목 과다 나열
5. 과거 사례 여러 개
6. 긴 인용문
7. 세부 기술 설명

핵심 사실, 불확실성, 다음 이벤트는 마지막까지 남깁니다.

## 13. 기존 문서를 업데이트할 때

기존 문서가 길면 새 내용을 뒤에 계속 붙이지 않습니다.

```text
기존 장문 읽기
→ 현재도 중요한 내용만 추림
→ 오래되거나 중복된 부분 삭제
→ 최신 핵심 내용 반영
→ 전체 분량을 기존의 절반 이하로 압축
```

즉 **업데이트는 문서를 길게 만드는 작업이 아니라 다시 압축하는 작업**입니다.

## 14. 작성 완료 체크

```text
[ ] 1분 핵심만 읽어도 내용이 이해된다
[ ] 핵심 근거가 3~5개 안쪽이다
[ ] 확정과 기대/추정이 섞이지 않았다
[ ] 결론과 관계없는 배경이 삭제됐다
[ ] 같은 설명이 반복되지 않는다
[ ] 다음 확인 이벤트와 핵심 리스크가 있다
[ ] 출처는 중요한 원자료 위주다
[ ] 가능하면 기존 문서의 절반 이하 분량이다
```
