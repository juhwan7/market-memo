# 문서 작성 가이드 — 읽히는 시장 메모

이 문서는 `market-memo`의 **시황·종목·산업/테마 등 실제 분석 콘텐츠**를 작성할 때 적용하는 공통 편집 규칙입니다.

목표는 정보량을 무작정 늘리는 것이 아니라 **30초 안에 전체 그림을 잡고, 5분 안에 핵심 논리를 이해하고, 필요할 때만 상세 근거로 내려갈 수 있게 만드는 것**입니다.

> 운영용 `README.md`, `AGENTS.md`, 출처 정책, 면책고지, 자동화 설명서는 문서 목적에 맞게 간결한 구조를 유지합니다. 아래 형식은 시장을 읽기 위한 분석 콘텐츠에 우선 적용합니다.

---

## 1. 모든 분석 문서의 기본 구조

```text
제목 + 기준일/현재 상태
      ↓
30초 요약
      ↓
5분 이해
      ↓
시장 체크포인트
      ↓
깊게 보기
      ↓
앞으로 볼 것
      ↓
출처·업데이트 내역
```

### A. 30초 요약

문서 맨 위에 배치합니다. 다음 네 질문에 짧게 답합니다.

1. 지금 무슨 일이 벌어지고 있나?
2. 왜 시작됐나?
3. 주식시장에서는 왜 중요한가?
4. 다음으로 무엇이 확인돼야 하나?

가능하면 4~6개 bullet 또는 작은 표 하나로 끝냅니다.

### B. 5분 이해

정보를 나열하지 말고 **원인 → 사건 → 현재 → 다음 단계**로 이어지는 흐름을 만듭니다.

예:

```text
미국의 문제
→ 정책 대응
→ 한국/기업에 요구
→ 실제 합의·계약
→ 시장에서 움직이는 산업
→ 다음 확인 이벤트
```

중간에 독자가 자연스럽게 궁금해할 질문을 제목으로 사용합니다.

- `왜 지금 이 이야기가 나왔을까?`
- `그런데 실제로 확정된 것은 무엇일까?`
- `이 뉴스가 왜 이 종목과 연결될까?`
- `발표가 나오면 재료는 끝나는 걸까?`

### C. 깊게 보기

수치, 공시, 사업구조, 세부 정책, 과거 사례, 출처 등은 이 아래에 둡니다.

처음 읽는 사람은 30초 요약과 5분 이해만 읽어도 전체 구조를 파악할 수 있어야 합니다.

---

## 2. 상태 라벨을 반드시 사용한다

중요한 사실은 아래 중 하나로 구분합니다.

- **[확정]** 공시·정부·거래소·기업 공식 발표 등으로 확인
- **[당사자 주장]** 기업·정부·관계자의 설명 또는 전망
- **[가능성 높음]** 복수 근거가 있으나 최종 확정 전
- **[시장 기대]** 시장·언론에서 기대하지만 공식 확정되지 않음
- **[추정]** 공개 사실을 바탕으로 한 분석
- **[확인되지 않음]** 루머 또는 검증 불충분

`검토`, `MOU`, `우선협상`, `계약`, `수주`, `착공`, `양산`, `상장예심 청구`, `예심 승인`, `상장 완료`를 서로 바꾸어 표현하지 않습니다.

---

## 3. 중요도에 차이를 둔다

모든 내용을 같은 강도로 쓰지 않습니다.

- `★★★` 반드시 알아야 하는 핵심
- `★★` 중요한 배경 또는 후속 변수
- `★` 참고용 세부정보

별표는 문서 전체에 남발하지 말고, 핵심 쟁점이나 일정에만 사용합니다.

---

## 4. 모든 핵심 사건에는 “그래서 왜 중요?”를 붙인다

사실을 제시한 뒤 가능하면 바로 시장 의미를 연결합니다.

```markdown
> **그래서 왜 중요?**
> 이 단계가 단순 협의인지 실제 계약인지에 따라 관련주의 재료 강도가 완전히 달라진다.
```

단, 공식 사실과 시장 해석을 같은 문장으로 섞지 않습니다.

---

## 5. 시장 체크포인트를 별도로 둔다

분석 문서에는 가능한 경우 아래를 짧게 정리합니다.

- **현재 재료 단계:** 기대감 / 협의 / 공식 발표 / 계약·수주 / 집행·착공 / 실적 반영
- **다음 강화 조건:** 어떤 뉴스가 나오면 재료가 커지는가
- **재료 소멸 조건:** 어떤 이벤트 뒤 기대감이 끝날 수 있는가
- **실제 수혜 확인:** 매출·수주·지분·공급계약 등 무엇으로 확인할 것인가
- **반론/리스크:** 다른 해석이 가능한 이유

종목·테마 문서라면 `직접 수혜 / 간접 수혜 / 전략투자 / 기대감 중심`도 구분합니다.

---

## 6. 표와 흐름도를 적극 사용한다

아래 내용은 긴 문장보다 표를 우선합니다.

- 시간순 사건
- 확정 / 미확정 비교
- 미국이 원하는 것 / 한국이 원하는 것
- 기업별 지분·사업 관계
- 일정과 발표 단계
- 관련 종목의 실제 연관성
- 긍정·부정 시나리오

인과관계가 중요한 경우에는 간단한 text flow를 사용합니다.

```text
경제지표 상승
→ 금리 기대 변화
→ 국채금리·달러 반응
→ 성장주 밸류에이션 변화
```

---

## 7. 한 줄 정리를 중간에 넣는다

긴 섹션 뒤에는 필요한 경우 한 문장으로 압축합니다.

> **한 줄 정리:** 숫자 자체보다 `예상 대비 차이 → 금리 반응 → 주가 반응` 순서로 읽는 것이 중요하다.

---

## 8. 숫자는 체감 가능한 기준과 함께 쓴다

가능하면 숫자만 던지지 않습니다.

- 전년/전분기 대비
- 회사 매출 또는 CAPEX 대비
- 전체 패키지 중 비중
- 과거 평균 또는 직전 수치 대비
- 동종 기업과 비교

비교 기준이 없으면 억지 비교를 만들지 않습니다.

---

## 9. 문단 길이

- 한 문단은 보통 2~5문장
- 한 화면을 가득 채우는 장문 문단 지양
- 핵심 문장은 문단 앞에 배치
- 같은 설명을 다른 표현으로 반복하지 않음
- 세부 정보는 `깊게 보기`로 내림

---

## 10. 문서 마지막은 반드시 앞으로 볼 것으로 끝낸다

최종 결론에서 다음을 다시 확인합니다.

1. 지금 어느 단계인가?
2. 이미 확정된 것은 무엇인가?
3. 아직 기대감인 것은 무엇인가?
4. 다음으로 나와야 할 뉴스·공시·일정은 무엇인가?
5. 무엇이 나오면 기존 투자 논리가 깨지는가?

목표는 `읽었을 때 많이 알게 되는 문서`보다 **다음 뉴스를 봤을 때 어디에 끼워 넣어야 하는지 바로 판단할 수 있는 문서**입니다.

---

## 11. 문서 유형별 적용

### 종목 분석

`30초 요약 → 투자자가 이 회사를 이해하는 핵심 구조 → 사업/재무 → 최근 재료 → 시장 체크포인트 → 리스크 → 깊게 보기 → 앞으로 볼 것`

### 산업·테마

`30초 요약 → 테마가 생긴 이유 → 돈/정책/기술 흐름 → 기업별 실제 연결 강도 → 현재 재료 단계 → 깊게 보기 → 다음 촉매와 소멸 조건`

### 시황·경제지표

`30초 요약 → 오늘 시장의 핵심 변수 → 원인과 전달경로 → 지수·금리·환율·수급 → 시나리오 → 발표 직후 체크 순서 → 깊게 보기`

## 12. 작성 완료 체크리스트

```text
[ ] 상단에 30초 요약이 있다
[ ] 5분 이해만 읽어도 전체 흐름이 이어진다
[ ] 사실과 추정이 라벨로 구분돼 있다
[ ] 중요한 사건에 시장 의미가 설명돼 있다
[ ] 긴 정보 나열은 표로 압축했다
[ ] 현재 재료 단계와 다음 촉매가 있다
[ ] 재료 소멸/반론/리스크가 있다
[ ] 상세 근거는 깊게 보기 아래에 있다
[ ] 마지막에 앞으로 볼 일정·키워드가 있다
[ ] 1차 출처와 마지막 업데이트 날짜가 있다
```
