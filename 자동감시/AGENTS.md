# 자동감시 작업 규칙

자동감시는 시간이 지나며 상태가 바뀌는 이벤트를 확인합니다. 잘못된 자동 변경은 오래된 메모보다 더 위험하므로 보수적으로 수정합니다.

## 절대 원칙

1. 거래소·법정공시·정부·규제기관·기업 공식 발표 등 1차 자료를 우선합니다.
2. 기사·SNS·커뮤니티만으로 상태를 확정 단계로 올리지 않습니다.
3. 공식 사이트 접속 실패·파싱 실패를 상태 변화로 해석하지 않습니다.
4. 확실하지 않으면 기존 상태를 유지합니다.
5. 의미 있는 변화가 없으면 문서·상태 파일·커밋을 만들지 않습니다.
6. 기준 문서를 갱신할 때는 새 내용을 계속 붙이지 말고 **현재 판단에 필요한 핵심만 남겨 압축**합니다.

## 감시 방식

### deterministic_github_action

KIND 신규상장 여부처럼 정형 데이터에서 기계적으로 판정 가능한 상태에 사용합니다.

- 현재 무신사 IPO가 해당
- 자동 PR 방식 유지
- `main` 직접 수정 금지

### ai_state_watch

정책·외교·기업 진행처럼 기존 문맥과 새 자료를 함께 봐야 하는 대상에 사용합니다.

```text
감시대상.yaml 확인
→ state_file 확인
→ 현재 기준 문서 읽기
→ 최신 1차 자료 확인
→ 필요 시 보조자료 교차검증
→ 의미 있는 변화 판정
→ 핵심 내용만 갱신
```

## 이전 버전 보존

기준 문서를 수정하기 전 기존 문서는 아래 경로에 보존합니다.

```text
자동감시/이력/<대상-id>/YYYY-MM-DD-HHMM-이전-버전.md
```

최신 기준 문서에는 아래만 짧게 남깁니다.

- 이전 상태 → 현재 상태
- 이번에 새로 확인된 핵심 변화
- 여전히 미확정인 것
- 다음 확인 이벤트

과거 세부 이력은 최신 문서에 반복하지 않고 이력 파일로 넘깁니다.

`공약 → 구체 정책안 → 법안 → 의회 의결 → 대통령 서명 → 실제 지급`

`제한 운행 → 규제 변화 → 도시 확대 → 운행대수 증가 → 경제성 공개 → 매출 반영`

### 중국의 Trump–Kim 중재 가능성

`언론 보도 → 중국 공식 언급 → 북한 반응 → 북미 실무접촉 → 정상회담 일정 → 합의/결렬`

- 관련 인덱스
- `최근-업데이트.md`
- 루트 `README.md`

## 보안

- API 키·토큰·비밀번호를 저장소에 직접 적지 않습니다.
- 인증 기능은 GitHub Secrets 또는 연결 서비스 권한을 사용합니다.
- 외부 입력을 그대로 쉘 명령으로 실행하지 않습니다.
- 비신뢰 PR 코드에 높은 쓰기 권한을 주지 않습니다.
