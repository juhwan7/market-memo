# 자동감시 작업 규칙

이 폴더의 코드는 시간이 지나며 상태가 변하는 이벤트를 자동 확인합니다. 잘못된 자동 변경은 오래된 메모보다 더 위험하므로 일반 문서보다 보수적으로 수정합니다.

## 절대 원칙

1. 자동 상태 변경의 근거는 거래소·법정공시·정부·기업 공식 발표 같은 1차 자료를 우선합니다.
2. 뉴스 기사·SNS·커뮤니티만으로 `현재 상태`를 자동 변경하지 않습니다.
3. 공식 사이트 접속 실패·HTML 구조 변경·파싱 실패를 `상태 변화`로 해석하지 않습니다.
4. 확실하지 않으면 기존 상태를 유지합니다. 즉 fail-closed 방식입니다.
5. 자동화는 `main`을 직접 수정하지 않고 변경 후보를 Pull Request로 만듭니다.
6. 상태가 바뀌어도 과거 진행 이력은 삭제하지 않습니다.

## 무신사 IPO v1

현재 자동화는 KRX KIND `신규상장기업현황`에서 `무신사`가 공식 확인되는지를 감시합니다.

- 감지되지 않음 → 기존 `상장예비심사 진행` 상태 유지
- 감지됨 → `신규상장 완료` 변경 후보 생성
- 6자리 종목코드 추출 성공 → `종목분석/한국주식/종목코드-무신사.md` 전환 초안 생성
- 종목코드 추출 실패 → IPO 상태만 갱신하고 한국주식 전환은 보류

중간 단계인 예심 승인·증권신고서·수요예측·공모가 확정까지 자동화하려면 각각 신뢰할 수 있는 공식 데이터 소스를 먼저 확보한 뒤 별도 감지기를 추가합니다. 현재 v1에서 기사 문구를 이용해 중간 단계를 추정하지 않습니다.

## 변경 시 함께 확인할 파일

- `자동감시/상태/*.json`
- `.github/workflows/ipo-watch.yml`
- 관련 종목/IPO 문서
- `최근-업데이트.md`
- 루트 `README.md`

## 보안

- API 키·토큰·비밀번호를 저장소에 직접 적지 않습니다.
- 인증이 필요한 기능은 GitHub Secrets를 사용합니다.
- 외부 입력을 그대로 쉘 명령으로 실행하지 않습니다.
- Pull Request에서 실행되는 비신뢰 코드를 높은 쓰기 권한으로 실행하지 않습니다.
