## 이번에 새로 확인된 내용

### Astra 수요가 처음으로 지출 데이터에 잡혔다

**[시장 데이터/Reuters·Ramp]** Reuters는 2026년 9월 19일 Ramp 최신 데이터를 인용해 GPT-6 Astra가 Ramp가 추적하는 enterprise AI 지출의 약 **13%**를 차지했고 Claude Fable은 약 **8%**였다고 보도했다. Ramp는 기업 카드·조달 거래를 기반으로 미국 기업의 AI 지출을 추적하는 플랫폼이므로, 설문이 아니라 실제 결제 흐름에 가까운 신호라는 점이 의미 있다.

다만 Ramp 공개 AI Index는 자사 고객 표본을 기반으로 하며 전체 기업 AI 시장을 대표하지 않는다. 따라서 `Astra 전체 시장점유율 13%`라고 표현하지 않는다.

**[플랫폼 데이터/Reuters·OpenRouter]** 같은 보도에서 OpenRouter는 9월 둘째 주 이용자가 OpenAI 모델에 쓴 금액이 Anthropic 모델 지출을 넘어섰고, 이 지표에서 OpenAI가 Anthropic을 앞선 것은 2년 반여 만에 처음이라고 밝혔다. OpenRouter의 공개 랭킹은 실제 API 사용량을 집계하지만 전체 API 시장이 아닌 OpenRouter 내부 트래픽이다.
