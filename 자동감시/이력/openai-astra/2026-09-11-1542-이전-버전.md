# OpenAI — GPT-6 Astra 수요·접근성·컴퓨트 상태

- **마지막 검증:** 2026-09-10 20:51 KST
- **이전 버전:** [2026-09-10 20:51 이전 버전](../../자동감시/이력/openai-astra/2026-09-10-2051-이전-버전.md)
- **이전 상태:** [확정] GPT-6 Pro 플랜별 접근성과 Chat 사용한도 공개
- **현재 상태:** **[확정] Astra rollout 과정에서 Plus·Pro·Business 대상 추가 사용량 reset 정책까지 공식 운영**
- **핵심:** OpenAI가 Astra를 단계적으로 확대하면서 플랜별 한도뿐 아니라 초기 수요 대응용 추가 사용량 reset까지 제공하고 있다. 신규 Pro 가입 중단은 여전히 확인되지 않았다.

## 1분 핵심

| 항목 | 현재 확인 내용 |
|---|---|
| Astra rollout | **[확정]** 제한된 조직부터 시작해 Plus·Pro·Business·Enterprise 및 API로 확대 중 |
| Chat GPT-6 Pro | **[확정]** Pro $100·$200, Business, Enterprise 대상. Plus는 Work·Codex에서 Astra 사용 |
| 추가 사용량 | **[확정]** 9월 3·4일 일부 Plus·Pro·Business 계정에 banked reset, 9월 7일 해당 플랜에 global reset 제공 |
| 신규 Pro 가입 중단 | **[확인되지 않음]** 실제 중단 공지는 없음 |

## 이번에 새로 확인된 내용

OpenAI Help Center가 9월 10일 `How banked Codex resets work`를 업데이트했다. **[확정]** Astra rollout의 일부로 자격을 갖춘 Plus·Pro·Business 계정에 9월 3·4일 저장 가능한 reset을 지급했고, 9월 7일에는 해당 플랜 사용자에게 즉시 적용되는 global reset을 제공했다.

**이전과 달라진 점:** 기존에는 `플랜별 접근성·사용한도`까지만 공식화돼 있었는데, 이제 초기 rollout에서 실제 사용량을 추가 공급하는 운영정책도 확인됐다. 이는 capacity 정상화 선언은 아니며 신규 가입 제한도 아니다.

## 왜 중요한가

**[해석]** `단계적 rollout + 플랜별 한도 + 추가 reset`이 동시에 사용된다는 것은 Astra 수요를 관리하면서 접근 범위를 넓히는 과정으로 볼 수 있다. 다만 reset 지급만으로 GPU 부족이나 공급병목 규모를 단정할 수 없다.

반도체·HBM·데이터센터 수혜도 실제 신규 CAPEX나 공급계약이 확인되기 전에는 **시장 기대**로 구분한다.

## 여전히 미확정

- 신규 Pro 구독의 실제 중단·재개
- Astra capacity 정상화 시점
- Astra 때문에 발생한 신규 GPU·데이터센터 CAPEX 규모
- Samsung·SK·Broadcom·TSMC의 Astra 직접 추가 계약

## 다음 확인 이벤트

- Astra 한도·가격·크레딧/reset 정책 추가 변경

- 신규 데이터센터·GPU·자체칩 CAPEX
- 주요 공급망 추가 계약
