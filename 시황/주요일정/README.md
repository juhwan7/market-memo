# 주요 시장 일정

시장에 영향을 줄 예정 이벤트와, 반복해서 사용할 수 있는 경제지표·통화정책 해석 가이드를 기록합니다.

예: 미국 CPI·PPI·고용지표, FOMC, 한국은행 금통위, ECB·BOJ, 옵션·선물 만기, 주요 기업 실적 발표, 정부 정책 발표, 산업 행사.

예정 시각은 가능하면 한국시간(KST)도 함께 적고 발표 예정일과 실제 발표일을 구분합니다.

## 현재 기준 문서

### 2026년 9월 FOMC

- [`2026년 9월 FOMC 해석 가이드`](2026-09-FOMC-해석-가이드.md)
  - 9월 15~16일 FOMC 일정과 한국시간 발표 시각
  - 현재 3.50~3.75% 기준금리와 7월 9대3 동결 투표
  - 6월 SEP·점도표와 9월 점도표에서 볼 핵심 숫자
  - GDP·실업률·PCE·Core PCE 전망 해석법
  - 동결/인상과 점도표 조합별 매파·비둘기 시나리오
  - 발표 직후 2년물·10년물·달러·Nasdaq 확인 순서
  - 의장 기자회견에서 확인할 표현과 한국 증시 전달 경로

### 2026년 9월 PPI·CPI

- [`2026년 9월 미국 PPI·CPI 발표 해석 가이드`](2026-09-미국-PPI-CPI-해석-가이드.md)
  - PPI·CPI·PCE 차이
  - Headline/Core, MoM/YoY, 기저효과
  - 생산자물가가 소비자물가로 전가되는 구조와 한계
  - Shelter·서비스·에너지·관세 영향 체크포인트
  - 발표 직후 미국 2년물·10년물·달러·Nasdaq 선물 확인 순서
  - 2026-09-10 PPI → 2026-09-11 CPI → 2026-09-15~16 FOMC 연결

향후 월별 CPI·PPI 일정은 새 문서를 계속 복제하기보다 CPI·PPI 해석 가이드를 기준 문서로 두고, 날짜·예상치·실제값만 최신 일정 문서에서 갱신하는 것을 우선합니다.

FOMC 자료도 회의 이후 실제 금리결정·점도표·SEP·기자회견 내용을 기존 가이드에 사후 업데이트해 `사전 기대`와 `실제 결과`를 구분해 남깁니다.
