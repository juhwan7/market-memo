# 주요 시장 일정

시장에 영향을 줄 예정 이벤트와, 반복해서 사용할 수 있는 경제지표 해석 가이드를 기록합니다.

예: 미국 CPI·PPI·고용지표, FOMC, 한국은행 금통위, ECB·BOJ, 옵션·선물 만기, 주요 기업 실적 발표, 정부 정책 발표, 산업 행사.

예정 시각은 가능하면 한국시간(KST)도 함께 적고 발표 예정일과 실제 발표일을 구분합니다.
