# 글로벌 시황

유럽·중국·일본 등 주요 해외시장과 지정학, 원유·가스·금속 등 글로벌 변수의 시장 영향을 기록합니다.

한국 증시와 미국 증시에 어떤 경로로 영향을 줄 수 있는지 함께 정리합니다.

> 새 글로벌 시황 문서도 [`시황-템플릿.md`](../시황-템플릿.md)와 [`문서 작성 가이드`](../../자료정책/문서-작성-가이드.md)의 `30초 요약 → 5분 이해 → 시장 체크포인트 → 깊게 보기 → 앞으로 볼 것` 구조를 적용합니다.

- [`국제유가 이해 가이드`](유가-이해-가이드.md)

  - OPEC+·미국 셰일·재고·달러·수요·선물곡선이 유가에 미치는 영향
