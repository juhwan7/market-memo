# 글로벌 시황

유럽·중국·일본 등 주요 해외시장과 지정학, 원유·가스·금속 등 글로벌 변수의 시장 영향을 기록합니다.

한국 증시와 미국 증시에 어떤 경로로 영향을 줄 수 있는지 함께 정리합니다.

## 현재 기준 자료

### 국제유가

- [`국제유가 이해 가이드`](유가-이해-가이드.md)
  - WTI·Brent·Dubai/Oman 차이와 원유 품질
  - OPEC+·미국 셰일·재고·달러·수요·선물곡선이 유가에 미치는 영향
  - 호르무즈 해협과 중동 공급차질이 중요한 이유
  - 정제마진·석유화학·항공·조선 등 한국 업종과의 연결
  - 2026년 9월 Brent 100달러대 고유가 국면의 배경과 향후 체크포인트

최신 시황 질문에서는 문서의 구조를 활용하되 유가·재고·OPEC+ 정책·중동 상황은 현재 시점의 공식 자료와 최신 보도로 다시 확인합니다.
