# 시황

매일 시장의 흐름을 빠르게 파악하되, 단순 숫자 나열이 아니라 **왜 움직였는지와 다음 거래일에 무엇을 확인해야 하는지**까지 연결하는 메모를 모으는 곳입니다.

새 시황·경제지표 문서는 [시황-템플릿.md](시황-템플릿.md)를 기본 골격으로 사용하고, [문서 작성 가이드](../자료정책/문서-작성-가이드.md)의 이해 중심 원칙을 시황에 맞게 압축 적용합니다.

## 기본 흐름

~~~text
3줄 핵심
→ 오늘 무슨 일이 있었나
→ 왜 움직였나
→ 금리·환율·선물·수급 전달경로
→ 주도 업종·종목
→ 다른 해석 가능성
→ 다음 거래일 체크포인트
→ 결론
~~~

산업·종목 심화문서처럼 모든 배경을 길게 반복하지 않고, 그날 시장을 이해하는 데 필요한 구조만 설명합니다.

## 분류 기준

- 한국증시/ : 코스피·코스닥, 수급, 프로그램, 선물, 환율, 주도 테마, 장중·마감 시황
- 미국증시/ : S&P 500·나스닥·다우, 미국 금리, 달러, 원자재, 주요 실적과 미국장 마감
- 글로벌/ : 유럽·중국·일본 등 글로벌 시장과 지정학·원자재 이슈
- 주요일정/ : CPI, PPI, FOMC, 한국은행, 옵션만기, 실적 발표 등 시장 일정

## 저장 규칙

날짜가 중요한 문서는 YYYY-MM-DD-제목.md 형식을 권장합니다.

~~~text
시황/한국증시/2026-09-10-오전장-시황.md
시황/미국증시/2026-09-10-미국장-마감.md
시황/주요일정/2026-09-주요-경제일정.md
~~~

시황 문서에서는 지수만 나열하지 않고 거래대금, 외국인·기관 수급, 선물·프로그램, 환율, 금리, 원자재, 주도 테마와 핵심 뉴스의 연결을 함께 기록합니다. 확보하지 못한 수치는 추정해서 채우지 않습니다.
