## 저장 규칙

시황 질문이나 일일 브리핑은 우선 이 폴더에 저장합니다. 날짜가 중요한 문서는 `YYYY-MM-DD-제목.md` 형식을 권장합니다.

예시:

```text
시황/한국증시/2026-09-10-오전장-시황.md
시황/미국증시/2026-09-10-미국장-마감.md
시황/주요일정/2026-09-주요-경제일정.md
```

시황 문서에서는 지수만 나열하지 않고 거래대금, 외국인·기관 수급, 선물·프로그램, 환율, 금리, 원자재, 주도 테마와 핵심 뉴스의 연결을 함께 기록합니다.
