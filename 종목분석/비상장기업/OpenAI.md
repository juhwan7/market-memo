## 이번에 새로 확인된 내용

### Perplexity가 Astra를 실제 프로덕션 시스템에 사용한다고 공개됐다

**[확정/당사자 사례]** OpenAI는 2026년 9월 14일 `Perplexity trusts GPT-6 Astra with end-to-end systems`라는 공식 고객 사례를 공개했다.

OpenAI가 공개한 Perplexity 공동창업자 Johnny Ho의 설명에 따르면 Astra는 다음 업무에 사용된다.

- 사용자·팀 커뮤니케이션 작성
- 실제 소프트웨어 시스템 변경
- 프로덕션 소프트웨어 모니터링
- 테스트용 프로그램 생성과 엔드투엔드 워크플로 검증

Perplexity 측은 이전 세대 모델보다 사람의 확인 빈도를 줄여 전체 시스템 단위의 작업을 맡길 수 있다고 설명했다.

이 사례가 중요한 이유는 Astra가 `벤치마크가 좋다`거나 `도입을 검토 중이다` 수준을 넘어 **외부 기술기업의 실제 운영 워크플로에서 사용되고 있다는 1차 자료**가 추가됐기 때문이다.

다만 OpenAI의 고객 사례는 공급자와 고객 당사자의 설명이다. 사용량·비용·성과를 독립적으로 검증할 수 있는 수치가 공개된 것은 아니다.

이번 변화는 `기업용 제품이 있다`에서 한 단계 더 나아가 **Astra가 실제 기업 운영 시스템에 투입된 구체적 사용 사례가 공식 공개됐다는 점**이다.

## 왜 중요한가

Astra의 기업 수요를 볼 때 증거 강도는 대략 다음 순서로 높아진다.

```text
제품 발표
→ design partner·시험 도입
→ 실제 프로덕션 업무 사용
→ 좌석·API 사용량 공개
→ 계약금액·ARR·매출 공개
```

Perplexity 사례는 `실제 프로덕션 업무 사용` 단계의 증거를 추가한다. 하지만 아직 뒤 단계인 **사용량·계약금액·매출 지표**는 공개되지 않았다.

따라서 이번 변화는 Astra의 enterprise adoption 근거를 강화하지만, OpenAI 실적을 수치로 끌어올릴 정도의 매출 증거로 보기는 이르다.

## 기존 접근성·capacity 상태

**[확정] OpenAI Help Center 기준:**

- **Pro $200:** GPT-6 Pro 주 200회
- **Pro $100:** GPT-6 Pro와 GPT-5.6 Sol Pro 합산 주 50회
- **Business Standard:** 두 Pro 모델 합산 월 15회
- **Business Premium:** 두 Pro 모델 합산 주 50회
- **Plus:** Chat의 GPT-6 Pro는 포함되지 않지만 Work·Codex에서 Astra 사용 가능

2026년 9월 10일부터 **Pro $200 신규 가입·업그레이드가 일시 중단**된 상태도 유지된다. 기존 Pro $200 구독자는 유지·갱신할 수 있으며 재개 시점은 공개되지 않았다.

## 컴퓨트 공급 확대 상태

**[확정]** Firmus와 OpenAI는 2026년 9월 8일 다년 전략적 파트너십을 발표했고, OpenAI는 말레이시아의 Firmus AI Factory 2곳에서 전용 AI 컴퓨트 용량을 계약했다.

Firmus는 신규 시설에 NVIDIA DSX AI Factory Platform과 Vera Rubin NVL72 시스템을 도입할 계획이라고 밝혔다.

다만 Firmus 전체 고객 계약용량 `900MW+`는 OpenAI 단독 계약량이 아니다. OpenAI 전용 MW·계약금액·정확한 가동일은 여전히 공개되지 않았다.

## 금융서비스 확장 상태

하지만 실제 유료 고객 수, 좌석 수, 계약금액, ARR·매출 기여도, 두 금융사의 전사 도입 범위는 공개되지 않았다.
