# OpenAI — GPT-6 Astra 수요·플랜 접근성·컴퓨트 상태

- **마지막 검증:** 2026-09-10 19:33 KST
- **이전 버전:** [2026-09-10 19:33 이전 버전](../../자동감시/이력/openai-astra/2026-09-10-1933-이전-버전.md)
- **이전 상태:** [당사자 주장] Astra 수요 폭증, 신규 Pro 구독 일시중단 가능성 검토
- **현재 상태:** **[확정] OpenAI가 Astra 기반 `GPT-6 Pro`의 플랜별 접근 범위와 구체 사용한도를 공식 도움말에 공개**
- **핵심:** 신규 Pro 가입 중단은 아직 확인되지 않았지만, Astra의 실제 제공 범위와 사용량 관리가 더 구체화됐다.

## 1분 핵심

| 항목 | 현재 확인 내용 |
|---|---|
| Chat에서 GPT-6 Pro | **[확정]** Pro $100·Pro $200·Business·Enterprise에서 제공. Enterprise는 워크스페이스 권한에 따라 달라짐 |
| Plus | **[확정]** Chat의 GPT-6 Pro가 아니라 Work·Codex에서 Astra 포함 |
| Chat 사용한도 | **[확정]** Pro $200 주 200회, Pro $100 주 50회, Business Standard 월 15회, Business Premium 주 50회 |
| 신규 Pro 가입 중단 | **[확인되지 않음]** 실제 중단 공지는 아직 없음 |

## 왜 중요한가

9월 9일에는 `수요가 너무 강하면 신규 Pro 구독을 잠시 막을 수 있다`는 OpenAI 책임자 발언이 핵심이었다. 9월 10일 공식 도움말은 한 단계 더 나아가 **어떤 플랜이 Astra를 어디서 쓸 수 있고 얼마나 쓸 수 있는지**를 명시했다.

이는 `수요 폭증 → 서비스 용량 관리 → 플랜별 사용량 차등화`가 실제 제품정책으로 구체화되고 있다는 신호다. 다만 **신규 가입 제한이나 capacity 정상화 발표로 상태가 바뀐 것은 아니다.**

## 핵심 근거

1. **[확정]** GPT-6 Pro는 GPT-6 Astra 기반이며 Pro $100·$200, Business, Enterprise의 Chat에서 제공된다.
2. **[확정]** Plus는 Astra를 Work와 Codex에서 사용하며 Chat의 GPT-6 Pro 대상에는 포함되지 않는다.
3. **[확정]** GPT-6 Pro Chat 사용한도가 플랜별로 공개됐다. Work·Codex allowance는 별도다.
4. **[당사자 주장]** Astra 수요가 전례 없이 강하며 신규 Pro 구독 제한 가능성이 있다는 기존 발언은 유지된다.
5. **[확인되지 않음]** OpenAI가 실제로 신규 Pro 가입을 중단했거나 GPU 부족을 공식 발표한 사실은 현재 확인되지 않는다.

## 시장 의미

**[해석]** 높은 수요 자체는 제품 경쟁력에 긍정적이지만, 사용한도 세분화는 추론 컴퓨트·서빙 비용과 capacity가 중요한 제약이라는 점도 보여준다. 반도체·HBM·데이터센터 수혜는 `Astra 인기`만으로 확정하지 않고 실제 CAPEX·공급계약을 확인해야 한다.

## 앞으로 볼 것

- 신규 Pro 가입 실제 중단·재개
- Astra 한도·가격·크레딧 정책 추가 변경
- Work·Codex 전면 rollout 또는 capacity 정상화
- 신규 데이터센터·GPU·자체칩 CAPEX
- Samsung·SK·Broadcom·TSMC 추가 공급계약
