# 비상장기업·IPO

상장을 준비 중이거나 비상장 상태인 주요 기업의 기업분석·IPO 진행 상황을 정리하는 폴더입니다.

## 저장 기준

- 상장예비심사 청구 전후의 IPO 추진 기업
- 증권신고서 제출 전 비상장 대형 기업
- 장외시장·프리IPO·기관투자 관련 기업
- IPO 여부와 무관하게 글로벌 산업·시장에 큰 영향을 주는 주요 비상장 기업
- 향후 국내 증시 수급이나 업종 밸류에이션에 영향을 줄 가능성이 큰 기업

## IPO 기업은 반드시 구분할 단계

`IPO 검토` → `주관사 선정` → `상장예비심사 청구` → `예심 승인` → `증권신고서 제출` → `수요예측` → `공모가 확정` → `청약` → `상장`

각 단계는 의미가 다르므로 기사에서 ‘상장 추진’이라고 표현하더라도 실제 공식 절차가 어디까지 진행됐는지 확인합니다.

IPO와 무관한 주요 비상장 기업은 기업의 제품·실적·자금조달·전략적 투자·산업 영향과 상태가 변하는 핵심 재료를 중심으로 관리합니다.
