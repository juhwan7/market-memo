# 종목분석

개별 기업을 깊게 조사한 메모를 모으는 곳입니다.

## 폴더 구분

- `한국주식/` : 코스피·코스닥 상장사
- `미국주식/` : NYSE·Nasdaq 등 미국 상장사
- `해외기업/` : 일본·유럽·중국·홍콩 등 한국·미국 이외 주요 해외 기업
- `비상장기업/` : IPO 추진기업·상장예비심사 기업·주요 비상장사

## 파일명 규칙

한국주식은 가능하면 종목코드를 함께 적습니다.

```text
종목분석/한국주식/005930-삼성전자.md
종목분석/한국주식/000660-SK하이닉스.md
```

미국주식은 티커를 함께 적습니다.

```text
종목분석/미국주식/NVDA-엔비디아.md
종목분석/미국주식/PLTR-팔란티어.md
```

해외기업은 읽기 쉬운 한국어 회사명을 우선하고 문서 상단에 현지 거래소·종목코드를 적습니다.

```text
종목분석/해외기업/소프트뱅크.md
```

비상장기업·IPO는 회사명과 핵심 주제를 사용합니다.

```text
종목분석/비상장기업/무신사-IPO.md
```
