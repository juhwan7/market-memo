# 해외기업

한국·미국 이외 시장에 상장된 기업이나 시장 맥락상 별도 추적할 가치가 있는 해외 기업을 정리하는 폴더입니다.

## 기본 분류

- 일본 상장사: 도쿄증권거래소(TSE) 등
- 유럽 상장사: 런던·프랑크푸르트·파리·스위스 등
- 중국·홍콩·대만 상장사
- 기타 해외 주요 기업

미국 증시에 ADR이 상장돼 있더라도 본사가 해외에 있고 현지 상장이 기업의 기준 시장이면 `해외기업/`에서 관리할 수 있습니다.

## 파일명

읽기 쉬운 한국어 기업명을 우선하고, 문서 상단에 현지 종목코드·거래소를 함께 적습니다.

예:

```text
종목분석/해외기업/소프트뱅크.md
종목분석/해외기업/TSMC.md
```

## 작성 원칙

해외 기업은 국내 기업보다 법인 구조와 상장 시장이 복잡할 수 있으므로 다음을 반드시 구분합니다.

- 지주회사와 사업 자회사
- 상장회사와 비상장 투자회사
- 직접 보유와 펀드 보유
- 자회사·관계회사·단순 투자
- 현지 통화와 원화 환산값
- 발표 완료와 향후 예정 거래

최신 수치가 필요한 경우 현지 거래소·기업 IR·법정 공시 등 1차 자료를 우선 확인합니다.
