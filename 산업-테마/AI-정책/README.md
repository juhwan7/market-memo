## 읽을 때 구분할 것

'AI 감속'이라는 표현 하나로 아래를 섞지 않습니다.

1. 안전평가 때문에 특정 훈련을 잠시 중단하는 것
2. 모델 출시 전 독립 평가를 의무화하는 것
3. 일정 능력 이상에서 개발·배포를 멈추는 것
4. 학습 컴퓨트나 훈련 규모 자체를 제한하는 것
5. 국가 간 합의로 전체 AI 개발 속도를 제한하는 것

시장 영향은 1번과 5번이 완전히 다르므로 실제 정책이 어느 단계인지 먼저 확인합니다.
