# 산업·테마

개별 종목보다 여러 기업을 함께 움직이는 산업, 정책, 기술 변화와 공급망을 이해하기 위한 문서입니다.

새 산업·테마 문서는 [산업-테마-템플릿.md](산업-테마-템플릿.md)를 기본 골격으로 사용하고, [문서 작성 가이드](../자료정책/문서-작성-가이드.md)의 이해 중심 심화형 구조를 적용합니다.

## 기본 흐름

~~~text
3줄 핵심
→ 왜 중요한가
→ 먼저 쉽게 이해하면
→ 수요가 생긴 이유
→ 공급망·병목·경쟁 구조
→ 현재 확인된 변화
→ 핵심 근거
→ 반론·다른 시나리오
→ 국내 기업 의미
→ 시간순 흐름
→ 앞으로 볼 지표
→ 결론
~~~

관련 종목을 많이 나열하기보다 매출, 수주, 고객사, 기술, 지분관계, 정책 수혜 구조가 실제로 연결되는지를 우선합니다.
