# 산업·테마

개별 종목보다 여러 기업을 함께 움직이는 산업, 정책, 기술 변화와 시장 테마를 정리하는 곳입니다.

> 새 산업·테마 문서는 [`산업-테마-템플릿.md`](산업-테마-템플릿.md)를 기본 골격으로 사용하고, [`문서 작성 가이드`](../자료정책/문서-작성-가이드.md)의 `30초 요약 → 5분 이해 → 시장 체크포인트 → 깊게 보기 → 앞으로 볼 것` 구조를 적용합니다.

```text
산업-테마/방산/
```

## 현재 기준 문서

### 핵융합 · 현대차

- [`현대차 핵융합 투자 전략`](핵융합/현대차-핵융합-투자-전략.md)
  - 현대차가 한일융합펀드 전략적 투자자로 핵융합 산업에 참여한 사실 확인
  - 실제 투자 대상은 Kyoto Fusioneering이며 현대차의 CFS 직접 투자 여부는 공식 확인되지 않음으로 구분
  - CFS의 SPARC·ARC, 고온초전도 자석, 2030년대 상용화 로드맵 설명
  - `기사 테마 → 기술 보유 → 실제 공급 → 글로벌 계약 → 수주·매출` 순서로 국내 수혜 강도 판단

### 미국 정책 · 재정

- [`트럼프 5,000달러 Trump Dividend 공약`](미국정책/트럼프-5000달러-배당-공약.md)
  - 중간선거에서 공화당이 하원·상원을 모두 유지할 경우 성인 시민 1인당 5,000달러 지급 공약
  - 지급 확정이 아닌 선거 공약 단계로 법안·예산·재원·지급방식 미확정
  - 총비용 약 1.2~1.35조달러 규모와 의회의 세출 승인 필요성 정리
  - DOGE 5,000달러 구상·관세 2,000달러 배당·Warrior Dividend·Trump Accounts와 구분
  - 실제 입법 시 소비·인플레이션·국채금리·성장주에 미칠 경로와 재료 강화/소멸 조건 추적

### Apple · 폴더블

- [`Apple iPhone Duo 출시 의미`](폴더블/애플-아이폰-듀오-출시-의미.md)
  - Apple 첫 폴더블 iPhone의 공식 사양·가격·출시 일정
  - Apple이 폴더블 시장에 늦게 진입한 배경과 시장 확대 논리
  - `실제 공급 → 생산량 → 가동률·수주 → 실적` 순서로 한국 공급망 수혜 판단
  - 10월 사전 주문·초기 판매·2세대 제품군을 다음 촉매로 추적

### 대미투자

- [`트럼프 대미투자 전략 지도`](대미투자/트럼프-대미투자-전략-지도.md)
  - 30초 안에 3,500억달러 구조와 확정/후보 상태 확인
  - 미국이 대미투자를 요구하는 배경과 한국의 방어조건
  - 조선·텍사스 가스발전·Alaska LNG·원전·반도체·핵심광물 상태 구분
  - `후보 → 선정 → 한국 기업 참여 → 수주 → 착공` 재료 강도 판단

### 로봇

- [`한국 대기업 로봇 사업 지도`](로봇/한국-대기업-로봇-사업-지도.md)
  - 대기업별 `자회사/경영권 → 최대주주 → 전략투자 → 협력` 관계 강도 구분
  - 상장 직접 연결 종목과 비상장 핵심 로봇회사 분리
  - 양산·공장투입·수주·실적까지 이어지는지 체크

## 테마 문서에서 볼 것

1. 30초 요약에서 현재 단계와 다음 촉매
2. 테마가 생긴 구조적 원인
3. 정책·기술·자금 흐름
4. 실제 수혜 구조
5. 대기업·핵심 기업의 지분·사업 관계
6. 대표 종목과 후발 종목의 실제 연관성
7. 거래대금·수급 특징
8. 과거 같은 재료의 주가 반응
9. 앞으로 남은 이벤트
10. 재료 소멸 가능성
11. 반론과 리스크
12. 원출처

기사에서 단순히 `관련주`로 묶었다는 이유만으로 포함하지 않고 매출, 수주, 고객사, 기술, 지분관계, 정책 수혜 구조를 확인합니다.
