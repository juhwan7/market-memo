# 산업·테마

개별 종목보다 여러 기업을 함께 움직이는 산업, 정책, 기술 변화와 시장 테마를 정리하는 곳입니다.

## 예시 분류

```text
산업-테마/대미투자/
산업-테마/폴더블/
산업-테마/로봇/
산업-테마/원전/
산업-테마/AI-반도체/
산업-테마/전력기기/
산업-테마/조선/
산업-테마/방산/
```

## 현재 기준 문서

### 폴더블

- [`Apple iPhone Duo 출시 의미`](폴더블/애플-아이폰-듀오-출시-의미.md)
  - Apple 첫 폴더블 iPhone의 공식 사양·가격·출시 일정
  - 애플이 폴더블 시장에 늦게 진입한 배경과 제품 전략
  - OLED·힌지·소재·기판·카메라 등 공급망 구조
  - 한국 공급망에서 실제 공급 확인과 단순 테마를 구분하는 기준
  - 10월 사전 주문·정식 출시 이후 확인할 판매·생산량 체크포인트

### 대미투자

- [`트럼프 대미투자 전략 지도`](대미투자/트럼프-대미투자-전략-지도.md)
  - 트럼프가 대미투자를 요구하는 배경
  - 한국의 3,500억달러 전략투자 구조
  - 미국이 원하는 투자와 한국이 원하는 투자 조건
  - 조선·텍사스 가스발전·알래스카 LNG·원전·반도체·핵심광물·AI 후보 상태
  - 한국 증시에서 실제 수혜와 기대감 테마를 구분하는 체크포인트

### 로봇

- [`한국 대기업 로봇 사업 지도`](로봇/한국-대기업-로봇-사업-지도.md)

3. 실제 수혜 구조

9. 앞으로 남은 이벤트
