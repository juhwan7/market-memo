# 테마 리서치

반복적으로 등장하는 산업·정책·이슈 테마를 종목 단위가 아니라 **테마 단위**로 정리하는 폴더입니다.

예시:

```text
themes/원전.md
themes/AI-반도체.md
themes/전력기기.md
themes/조선.md
themes/방산.md
```

## 테마 문서에 포함할 내용

1. 테마의 정의
2. 최근 시장에서 부각된 계기
3. 핵심 정책·산업 배경
4. 실제 수혜 구조
5. 대표 종목과 2등주/후발주 구분
6. 각 종목의 실제 연관성
7. 최근 거래대금·수급 특징
8. 과거 같은 재료가 나왔을 때의 주가 반응
9. 향후 남아 있는 이벤트
10. 재료 소멸 가능성
11. 반론과 주요 리스크
12. 원출처

## 중요 원칙

- 단순히 기사에서 특정 종목을 '관련주'라고 불렀다는 이유만으로 편입하지 않습니다.
- 실제 매출, 수주, 고객사, 기술, 지분관계, 정책 수혜 구조 등 근거를 확인합니다.
- `직접 수혜`, `간접 수혜`, `기대감 중심`, `연관성 낮음`을 구분합니다.
- 대장주는 단순 상승률이 아니라 거래대금, 시가총액, 뉴스 민감도, 과거 시장 주도 이력 등을 함께 봅니다.
- 발표가 이미 끝난 재료와 앞으로 남은 이벤트를 구분합니다.
