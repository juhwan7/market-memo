# market-memo

한국·미국 주식시장의 시황, 종목, 산업·테마를 **빠르게 핵심을 잡고, 필요하면 배경과 구조까지 깊게 이해하기 위한 개인 시장 메모**입니다.

목표는 단순히 정보를 많이 쌓는 것이 아니라 **무슨 일 → 왜 중요 → 왜 생겼나 → 실제 근거 → 반론 → 투자 의미 → 다음 확인사항**을 연결해서 이해하는 것입니다.

> [!IMPORTANT]
> 개인 학습·시장 분석용이며 투자 권유가 아닙니다. 중요한 판단 전 DART·KRX·SEC·기업 IR·정부기관 등 원문을 다시 확인합니다.

## 기본 작성 형식

분석 문서는 원칙적으로 다음 흐름을 사용합니다.

~~~text
3줄 핵심
→ 왜 중요한가
→ 먼저 쉽게 이해하면
→ 배경·원인·구조
→ 핵심 근거
→ 반론·다른 시나리오
→ 투자 관점
→ 시간순 흐름
→ 앞으로 볼 지표
→ 핵심 결론
→ 기억할 한 문장
~~~
