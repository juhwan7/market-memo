# market-memo

한국·미국 주식시장의 흐름을 파악하고, 종목·테마·공시·뉴스·수급 등 시장 판단에 필요한 정보를 개인적으로 축적하는 **AI 기반 개인 시황 노트**입니다.

핵심 목적은 단순 종목 추천이 아니라 **시황 파악 → 핵심 이슈 정리 → 관련 종목·테마 연결 → 과거 사례 축적 → AI가 다시 참고할 수 있는 시장 맥락 저장**입니다.

> [!IMPORTANT]
> 이 저장소는 개인적인 학습 및 시장 분석을 위한 자료입니다. 투자 권유 또는 매수·매도 추천을 목적으로 하지 않습니다. AI를 활용한 조사·요약이 포함될 수 있으며 오류·누락·시차가 있을 수 있습니다. 실제 투자 판단 전 DART, 한국거래소, SEC, 기업 IR, 정부기관 등 원문 자료를 직접 확인해야 합니다.

## 질문별 자동 분류 원칙

- `삼성전자 분석` → `종목분석/한국주식/005930-삼성전자.md`

## README 자동 갱신 원칙

자료가 추가되거나 기존 자료의 핵심 내용이 크게 바뀌면 AI는 작업 종료 전에 다음을 함께 확인합니다.

1. `최근-업데이트.md`에 날짜·경로·변경 내용을 추가합니다.
2. 이 README의 `최근 업데이트`에 최근 핵심 변경을 반영합니다.
3. 새 카테고리나 중요한 기준 문서가 생겼다면 `바로가기`, `저장소 구조`, `현재 핵심 자료`도 수정합니다.
4. README의 최근 업데이트는 너무 길어지지 않도록 최근 핵심 5~10건 위주로 유지합니다.
5. 오래된 기록을 삭제하는 대신 `최근-업데이트.md`에 남겨 과거 변경 이력을 보존합니다.

즉, **자료 파일만 추가하고 README와 최근 업데이트 기록을 방치하지 않는 것**을 기본 원칙으로 합니다.

## 조사 원칙

- DART·SEC·거래소·기업 IR·정부 등 **1차 자료를 우선**합니다.
- 중요한 숫자·지분율·계약·인수·IPO 진행 단계는 최신 원문으로 다시 확인합니다.
- `확인된 사실`, `당사자 주장`, `시장 기대`, `해석·추정`, `확인되지 않음`을 구분합니다.
- 뉴스 하나만으로 주가 상승·하락 원인을 단정하지 않습니다.
- 공시, 거래대금, 수급, 테마, 지수, 환율, 금리, 원자재를 함께 봅니다.
- 기사·유료 리포트 원문과 저작권이 불명확한 이미지는 저장소에 복제하지 않습니다.

자세한 규칙은 [`자료정책/출처-정책.md`](자료정책/출처-정책.md)를 참고합니다.

## AI 활용

이 저장소는 ChatGPT 같은 AI가 과거 자료를 다시 읽어 **“이 뉴스가 예전에 어떤 테마를 움직였는지”, “지금 재료가 새로운지 이미 소멸한 재료인지”, “비슷한 시장 환경이 과거에 있었는지”**를 연결하기 위한 개인 시장 메모를 지향합니다.

AI가 작성한 내용 자체는 출처가 아니며 핵심 사실은 원문으로 검증합니다.

## 파일 이름

사용자가 읽기 쉽게 **한국어 파일명과 폴더명을 우선**합니다. 다만 `README.md`, `AGENTS.md`처럼 도구 호환성과 관례상 유용한 이름은 유지합니다.

한국 종목은 `종목코드-종목명.md`, 미국 종목은 `티커-한글종목명.md`, 비상장·IPO 기업은 `회사명-IPO.md`, 날짜별 시황은 `YYYY-MM-DD-제목.md` 형식을 권장합니다.
