# market-memo

한국·미국 주식시장의 흐름을 파악하고, 종목·테마·공시·뉴스·수급 등 시장 판단에 필요한 정보를 개인적으로 축적하는 **AI 기반 개인 시황 노트**입니다.

핵심 목적은 **시황 파악 → 핵심 이슈 정리 → 관련 종목·테마 연결 → 과거 사례 축적 → 최신 상태 재검증**입니다.

> [!IMPORTANT]
> 이 저장소는 개인 학습 및 시장 분석용입니다. 투자 권유 또는 매수·매도 추천을 목적으로 하지 않습니다. AI를 활용한 조사·요약이 포함될 수 있으며 실제 판단 전 DART, KRX, SEC, 기업 IR, 정부기관 등 원문을 다시 확인해야 합니다.

## 최신성 관리

시장 자료는 작성 당시에는 맞아도 시간이 지나면 틀릴 수 있습니다. 따라서 IPO·M&A·임상·수주·지수편입·정책·규제·외교처럼 상태가 변하는 자료는 과거 문장을 그대로 현재 사실로 사용하지 않습니다.

AI가 최신 질문에 답할 때는 기존 문서의 `마지막 업데이트`와 현재 상태를 확인하고, 중요한 상태는 최신 원문으로 다시 검증하는 것을 원칙으로 합니다.

### AI 상태감시

`감시대상.yaml`에서 `watch_mode: ai_state_watch`로 등록된 자료는 기존 문맥과 최신 원문을 비교해 의미 있는 상태 변화가 있을 때 갱신합니다.

갱신 순서는 다음과 같습니다.

```text
현재 기준 문서 읽기
        ↓
최신 공식자료·신뢰도 높은 보도 확인
        ↓
실제 변화인지 재탕인지 판정
        ↓
변화가 있으면 이전 문서 전체를 이력으로 보존
        ↓
최신 문서에
이전 버전 링크 + 달라진 점 + 현재 단계 + 다음 단계
        ↓
상태 JSON + 최근-업데이트.md + README 갱신
```

기사만 존재하고 공식 확인이 없으면 `보도` 단계로는 기록할 수 있지만 확정 상태로 자동 승격하지 않습니다. 의미 있는 변화가 없으면 문서도 커밋도 만들지 않습니다.

자세한 규칙은 [`자동감시/README.md`](자동감시/README.md)를 참고합니다.

OpenAI Astra 자료는 신규 Pro 가입 실제 중단·재개, Astra 플랜 접근성·usage limit·가격 변화, capacity 정상화, 신규 데이터센터·자체칩·메모리 공급계약과 CAPEX가 확인될 때 최신 기준 문서를 갱신합니다. 직원 발언만으로 공식 회사정책이나 공급계약을 확정하지 않습니다.

미국 재정정책 자료는 선거 공약·백악관 정책안·법안 발의·의회 통과·예산 확정·실제 집행 단계를 서로 구분합니다. `Trump Dividend`도 법안·재원·지급대상·의회 통과 여부가 확인되기 전까지 지급 확정으로 표현하지 않습니다.

Tesla Cybercab 자료는 차량 공개와 실제 운행을 구분하고 NHTSA 규제상태, 운행 도시·차량수, 생산량, 운임·가동률·Robotaxi 매출이 바뀌면 최신 기준 문서를 갱신합니다.

한반도 외교 자료는 언론의 중재 가능성 보도와 중국·북한·미국 정부의 공식 행동을 구분하며, 실무접촉·정상회담 일정·합의가 확인될 때 상태를 단계적으로 올립니다.

경제지표 문서는 BLS·BEA·Federal Reserve의 공식 일정과 실제 발표값을 우선하며, 시장 컨센서스·금리선물 확률은 발표 직전 다시 확인합니다.

FOMC 자료는 회의 전 시장 기대와 회의 후 실제 결과를 구분합니다. 실제 금리결정·점도표·SEP·투표·기자회견이 공개되면 사전 전망 문장을 그대로 현재 사실처럼 사용하지 않고 결과를 다시 반영합니다.

유가 자료는 WTI·Brent 가격, EIA 재고, OPEC+ 생산정책, 중동 지정학과 운항 상황이 빠르게 바뀌므로 최신 질문에서 반드시 재검증합니다.

Apple iPhone Duo 자료도 10월 사전 주문·정식 출시 이후 실제 판매량, 생산 목표, 초기 내구성 평가와 한국 공급업체 수주 확인 여부가 바뀌면 기준 문서를 갱신합니다.

`대미투자` 문서도 첫 전략투자 프로젝트 선정, 텍사스 발전·미국 원전·Alaska LNG의 상태 변화, 한국 기업의 실제 수주가 나오면 기존 기준 문서를 갱신하고 과거 상태를 이력으로 남깁니다.

        ↓
