# market-memo

한국·미국 주식시장의 흐름을 파악하고 종목·테마·공시·뉴스·수급 등 시장 판단에 필요한 정보를 개인적으로 축적하는 **AI 기반 개인 시황 노트**입니다.

핵심 목적은 **시황 파악 → 핵심 이슈 정리 → 관련 종목·테마 연결 → 과거 사례 축적 → 최신 상태 재검증**입니다.

> [!IMPORTANT]
> 이 저장소는 개인 학습 및 시장 분석용입니다. 투자 권유 또는 매수·매도 추천을 목적으로 하지 않습니다. AI를 활용한 조사·요약이 포함될 수 있으며 실제 판단 전 DART, KRX, SEC, 기업 IR, 정부기관 등 원문을 다시 확인해야 합니다.

## 문서를 읽는 방식

이 저장소의 실제 시장 분석 문서는 **처음부터 끝까지 정독하지 않아도 핵심을 잡을 수 있게** 아래 순서로 작성합니다.

```text
30초 요약
   ↓
5분 이해
   ↓
시장 체크포인트
   ↓
깊게 보기
   ↓
앞으로 볼 것
```

### 30초 요약

- 지금 무슨 일이 벌어지는지
- 왜 시작됐는지
- 시장에서는 왜 중요한지
- 이미 확정된 것과 아직 기대감인 것
- 다음으로 무엇을 봐야 하는지

### 5분 이해

정보를 나열하기보다 `배경 → 원인 → 사건 → 현재 상태 → 다음 단계`가 이어지도록 설명합니다.

### 상태 라벨

- **[확정]** 공식 자료로 확인
- **[당사자 주장]** 기업·정부·관계자 설명
- **[가능성 높음]** 근거는 있으나 최종 확정 전
- **[시장 기대]** 시장·언론에서 기대하는 단계
- **[추정]** 공개 사실을 바탕으로 한 분석
- **[확인되지 않음]** 검증 불충분

중요한 내용은 필요에 따라 `★★★ / ★★ / ★`로 구분하고, 핵심 사건에는 **“그래서 왜 중요?”**를 붙여 시장 의미를 연결합니다.

자세한 규칙은 [`자료정책/문서-작성-가이드.md`](자료정책/문서-작성-가이드.md)를 참고합니다.

## 최신성 관리

시장 자료는 작성 당시에는 맞아도 시간이 지나면 틀릴 수 있습니다. IPO·M&A·임상·수주·지수편입·정책처럼 상태가 변하는 자료는 과거 문장을 그대로 현재 사실로 사용하지 않습니다.

AI가 최신 질문에 답할 때는 기존 문서의 `마지막 업데이트`와 현재 상태를 확인하고, 중요한 상태는 최신 원문으로 다시 검증합니다.

경제지표 문서는 BLS·BEA·Federal Reserve의 공식 일정과 실제 발표값을 우선하며, 시장 컨센서스·금리선물 확률은 발표 직전 다시 확인합니다.

대미투자는 첫 전략투자 프로젝트 선정, 텍사스 발전·미국 원전·Alaska LNG 상태, 한국 기업 실제 수주가 바뀌면 기준문서를 갱신합니다.

## 무신사 IPO 자동 감시

현재 자동화의 첫 대상입니다.

```text
상장예비심사 진행
→ KRX KIND 신규상장기업현황 정기 확인
→ 무신사 신규상장 공식 확인
→ IPO 문서 상태 자동 수정
→ 최근-업데이트.md + README 갱신
→ 종목코드 확인 시 한국주식 전환 초안 생성
→ 자동 PR 생성
```

자동 감시는 기사나 검색 결과만으로 상태를 변경하지 않습니다. KIND 접속·파싱에 실패하면 기존 상태를 유지하는 fail-closed 방식입니다.

자세한 동작은 [`자동감시/README.md`](자동감시/README.md)를 참고합니다.

## 조사 원칙

- DART·SEC·KRX·기업 IR·정부 등 **1차 자료 우선**
- 중요한 숫자·지분율·계약·인수·IPO 단계는 최신 원문 재확인
- `확인된 사실 / 당사자 주장 / 시장 기대 / 해석·추정 / 확인되지 않음` 구분
- 기사 하나만으로 주가 상승·하락 원인을 단정하지 않음
- 기사·유료 리포트 원문과 저작권이 불명확한 이미지는 저장소에 복제하지 않음
- 정확성이 문서 분량보다 우선

자세한 검증 규칙은 [`자료정책/출처-정책.md`](자료정책/출처-정책.md), 작성 형식은 [`자료정책/문서-작성-가이드.md`](자료정책/문서-작성-가이드.md)를 따릅니다.
