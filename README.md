# market-memo

한국·미국 주식시장의 시황, 종목, 산업·테마를 **짧고 빠르게 이해하기 위한 개인 시장 메모**입니다.

목표는 정보를 많이 쌓는 것이 아니라 `무슨 일 → 왜 중요 → 핵심 근거 → 다음 확인사항`을 빠르게 잡는 것입니다.

> [!IMPORTANT]
> 개인 학습·시장 분석용이며 투자 권유가 아닙니다. 중요한 판단 전 DART·KRX·SEC·기업 IR·정부기관 등 원문을 다시 확인합니다.

## 문서 작성 원칙

모든 새 분석 문서는 아래 순서를 기본으로 합니다.

```text
1분 핵심
→ 왜 중요한가
→ 핵심 근거
→ 앞으로 볼 것
→ 출처
```

- 일반 문서: 가능하면 **800~1,800자**
- 복잡한 자료: 특별한 이유가 없으면 **2,500자 이하**
- 핵심 근거: **3~5개**
- 표: 최대 **2개**
- 긴 배경·반복 설명·관련주 과다 나열은 삭제
- 기존 장문 갱신 시 새 내용을 붙이기보다 전체를 다시 압축

세부 기준은 [`자료정책/문서-작성-가이드.md`](자료정책/문서-작성-가이드.md)를 따릅니다.

## 사실과 해석

중요 내용은 필요할 때 다음처럼 구분합니다.

- **[확정]** 공식 자료로 확인
- **[당사자 주장]** 기업·정부 등의 주장
- **[가능성 높음]** 복수 근거가 있으나 최종 확정 전
- **[시장 기대]** 시장 기대지만 공식 확정 전
- **[추정]** 공개 사실을 바탕으로 한 분석
- **[확인되지 않음]** 검증 불충분

## 자동감시

- `deterministic_github_action`: KRX KIND처럼 기계적으로 확인 가능한 상태
- `ai_state_watch`: 정책·외교·기업 진행처럼 문맥 판단이 필요한 상태

의미 있는 변화가 있을 때만 갱신합니다. 기준 문서가 길어졌다면 최신 핵심 상태만 남기고 이전 내용은 이력으로 보존합니다.
