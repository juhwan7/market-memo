# market-memo

한국·미국 주식시장의 흐름을 파악하고, 종목·테마·공시·뉴스·수급 등 시장 판단에 필요한 정보를 개인적으로 축적하는 **AI 기반 개인 시황 노트**입니다.

핵심 목적은 **시황 파악 → 핵심 이슈 정리 → 관련 종목·테마 연결 → 과거 사례 축적 → 최신 상태 재검증**입니다.

> [!IMPORTANT]
> 이 저장소는 개인 학습 및 시장 분석용입니다. 투자 권유 또는 매수·매도 추천을 목적으로 하지 않습니다. AI를 활용한 조사·요약이 포함될 수 있으며 실제 판단 전 DART, KRX, SEC, 기업 IR, 정부기관 등 원문을 다시 확인해야 합니다.

## 최신성 관리

시장 자료는 작성 당시에는 맞아도 시간이 지나면 틀릴 수 있습니다. 따라서 IPO·M&A·임상·수주·지수편입·정책처럼 상태가 변하는 자료는 과거 문장을 그대로 현재 사실로 사용하지 않습니다.

AI가 최신 질문에 답할 때는 기존 문서의 `마지막 업데이트`와 현재 상태를 확인하고, 중요한 상태는 최신 원문으로 다시 검증하는 것을 원칙으로 합니다.

경제지표 문서도 같은 원칙을 적용합니다. BLS·BEA·Federal Reserve의 공식 일정과 실제 발표값을 우선하며, 시장 컨센서스·금리선물 확률은 발표 직전 다시 확인합니다.

유가 자료는 WTI·Brent 가격, EIA 재고, OPEC+ 생산정책, 중동 지정학과 운항 상황이 빠르게 바뀌므로 최신 질문에서 반드시 재검증합니다.

Apple iPhone Duo 자료도 10월 사전 주문·정식 출시 이후 실제 판매량, 생산 목표, 초기 내구성 평가와 한국 공급업체 수주 확인 여부가 바뀌면 기준 문서를 갱신합니다.

`대미투자` 문서도 첫 전략투자 프로젝트 선정, 텍사스 발전·미국 원전·Alaska LNG의 상태 변화, 한국 기업의 실제 수주가 나오면 기존 기준 문서를 갱신하고 과거 상태를 이력으로 남깁니다.

### 무신사 IPO 자동 감시

현재 자동화의 첫 대상입니다.

```text
현재: 상장예비심사 진행
        ↓
KRX KIND 신규상장기업현황 정기 확인
        ↓
무신사 신규상장 공식 확인
        ↓
IPO 문서 현재 상태 자동 수정
        ↓
최근-업데이트.md + README 갱신
        ↓
종목코드 확인 시 한국주식 전환 초안 생성
        ↓
자동 PR 생성 → 확인 후 병합
```

자동 감시는 **기사나 검색 결과만으로 상태를 변경하지 않습니다.** KIND 접속·파싱에 실패해도 기존 상태를 유지하는 fail-closed 방식입니다.

자세한 동작은 [`자동감시/README.md`](자동감시/README.md)를 참고합니다.

- DART·SEC·KRX·기업 IR·정부 등 **1차 자료 우선**
- 중요한 숫자·지분율·계약·인수·IPO 단계는 최신 원문 재확인
- `확인된 사실 / 당사자 주장 / 시장 기대 / 해석·추정 / 확인되지 않음` 구분

- 기사·유료 리포트 원문과 저작권이 불명확한 이미지는 저장소에 복제하지 않음
