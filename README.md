# market-memo

한국·미국 주식시장의 흐름을 파악하고, 종목·테마·공시·뉴스·수급 등 시장 판단에 필요한 정보를 개인적으로 축적하는 **AI 기반 개인 시황 노트**입니다.

핵심 목적은 **시황 파악 → 핵심 이슈 정리 → 관련 종목·테마 연결 → 과거 사례 축적 → 최신 상태 재검증**입니다.

> [!IMPORTANT]
> 개인 학습·시장 분석용 저장소입니다. 투자 권유가 아니며, 중요한 판단 전 DART·KRX·SEC·기업 IR·정부기관 등 원문을 다시 확인합니다.

## 최신성 관리

IPO·M&A·정책·규제·외교·기업 실적처럼 상태가 바뀌는 자료는 과거 내용을 현재 사실처럼 사용하지 않습니다. 최신 질문에서는 기준 문서의 마지막 검증일을 보고 공식 원문을 다시 확인합니다.

### AI 상태감시

`감시대상.yaml`의 `watch_mode: ai_state_watch` 대상은 기존 문서와 최신 자료를 비교해 의미 있는 변화가 있을 때만 갱신합니다.

```text
기존 기준 문서
→ 최신 공식자료 확인
→ 실제 변화인지 판정
→ 이전 버전 이력 보존
→ 최신 문서에 달라진 점·현재 단계·다음 단계 기록
→ 최근-업데이트.md + README 갱신
```

현재 주요 AI 상태감시 대상:

- TSMC AI 수요·월매출·CAPEX·2nm/CoWoS
- OpenAI Astra 수요·컴퓨트 capacity
- Tesla Cybercab 규제·운행 확대
- Trump Dividend 정책 단계
- 중국의 Trump–Kim 중재 가능성

기사 재탕이나 루머만으로 확정 상태를 올리지 않으며, 의미 있는 변화가 없으면 커밋하지 않습니다.

무신사 IPO는 KRX KIND를 확인하는 결정형 GitHub Actions 감시를 별도로 사용합니다.
