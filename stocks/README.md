# 종목 인덱스

개별 종목 리서치 문서를 빠르게 찾기 위한 인덱스입니다.

새 종목을 추가하거나 기존 종목을 크게 업데이트할 때 이 표도 함께 갱신합니다.

| 종목명 | 코드 | 주요 업종 | 주요 테마 | 최근 업데이트 | 한줄 요약 |
|---|---:|---|---|---|---|

아직 등록된 종목이 없습니다.

## 파일명 규칙

```text
stocks/종목코드-종목명.md
```

예:

```text
stocks/005930-삼성전자.md
stocks/000660-SK하이닉스.md
```

종목 문서는 [`_TEMPLATE.md`](_TEMPLATE.md)를 기준으로 작성합니다.
